# Resume Template

`vivek_energy_resume.tex` is the default premium LaTeX resume format for every generated resume.

Generation rules:

- Keep this visual format by default.
- Replace `{{JOB_TITLE}}` and `{{COMPANY}}` for each job.
- Save generated PDFs using:

```text
Vivek_Aryasomayajula_<Company>_<Role>_Resume.pdf
```

- Store generated PDFs outside Git in `resume/generated/`.
- Upload production PDFs to Supabase storage when configured.
- Do not add unverified experience or fake claims.
